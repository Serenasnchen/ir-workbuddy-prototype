# 业绩会问题雷达（ir-qa-radar）

先加载 `ir-house-style`。本技能的产物是**内部准备材料**，只索引已公开的表述，不替管理层写答案。

## 输入
- 本公司最近 4–12 个季度的业绩会实录（官方录音转写或第三方文字稿）。
- 最近一季的业绩新闻稿与演示材料。
- 业绩后至今的公开信息：港交所公告、官方新闻稿、主流媒体报道、券商公开观点（标二手）。

## 步骤
1. **解析实录（脚本）**：`python scripts/parse_transcripts.py <实录目录> <输出目录>`，得到逐段发言（发言人、机构、角色）。脚本会依据主持人交接语修正发言人；无法确认的标“待录音复核”。
   支持三种实录格式：StockAnalysis 网页（.html）、英文“Name: text”逐行文本，以及实操包的中文标注格式“发言人（机构，管理层/分析师/主持人）：正文”（全角或半角括号、逗号、冒号均可，一段一个发言，段间空行；UTF-8，可带 BOM）；中文标注的角色和机构按原文采用，写明的发言人姓名不改。不符合标注格式的段落（如缺角色、角色写成其他词、“Operator：…”）单独成条，角色为推断，标 `needs_review` 与“待录音复核”；括号里机构为空时，只有交接语点到的是同一人（或发言人为“Speaker N”）才用交接语补机构，否则标 `needs_review`。
2. **拆问题、打标签**：把每位分析师的发言拆成单个问题，按 `references/taxonomy.md` 的 15 类话题打标签，并记录证据短语。这一步需要逐条阅读判断，不能只靠关键词。拆分口径：同一段发言里用“first / second / separately / on the other hand”等引出的不同问题各算一个单元；管理层回答后同一分析师就同一问题的追问并入原单元，不另计。结果存为 `question_units.json`：`{"units": [{"quarter": "2025Q3", "analyst": "...", "org": "...", "topics": ["AI_CAPEX"], "evidence": {"AI_CAPEX": "原文短语"}}]}`；`quarter` 写“2025Q3”或实录文件名（如 `tencent_q3-2025`）均可。
3. **双轨热度（脚本）**：`python scripts/heat.py <解析目录> --units question_units.json --out heat.json`，按季度先后取最近 4 季（`--last` 可改），分别计算“管理层主动提及”（话题词表命中）与“分析师追问”（问题单元话题占比，脚本同时输出问题单元数作为样本量），并输出两者的缺口。每个话题附中性方向标签：“分析师关注度高于管理层主动提及”“管理层主动提及高于分析师关注度”或“两者接近”，成稿照此描述，不得改写为“被低估 / 被高估 / 讲得少 / 着墨少”等评价性说法。
4. **机构话题轨迹**：按机构汇总历季追问的话题。预测只做到“该机构过去关注 X，可能延续”，不生成以分析师真名署名的模拟发言。
5. **生成预测问题**：结合热度、机构轨迹与业绩后的新事件，产出 24–30 个议题级问题，每题给出：为什么现在会被问、市场证据（带出处）、热度 1–5、敏感度 1–5。
6. **已公开表述索引**：为每题找出管理层已公开的原话（逐字、出处、日期、层级、核查状态）。找不到就标“暂无已公开表述（工具只标注，不建议口径）”，并汇总进“暂无已公开表述清单”。
7. **口径漂移检测**：对同一议题，比对中英文、不同场合的说法（如中文媒体稿与英文实录），列出不一致之处。
8. **预注册（脚本）**：业绩会前选出 Top10 议题，写成 `top10_prereg.json`（`{"company", "call_date", "topics": [{"rank", "topic", "why"}]}`），运行 `python scripts/prereg.py seal top10_prereg.json` 生成 `top10_prereg.sealed.json`（SHA-256 指纹与 UTC 时间）；提交前用 `python scripts/prereg.py verify top10_prereg.sealed.json <sha256>` 复核；会后用 `python scripts/prereg.py score top10_prereg.sealed.json <实际提问话题.json>` 核对命中情况。

## 输出
- `radar.json`（问题、热度、敏感度、已公开表述索引、暂无已公开表述清单、口径漂移）。
- `radar.md`（一页摘要 + 暂无已公开表述清单，可导出 Word / 腾讯文档）。
- `top10_prereg.sealed.json` 与其 SHA-256。

## 红线
- 不代拟答复，不建议口径，不推测未披露数字。
- 不评价管理层：不用“被低估 / 被高估 / 讲得少 / 叙事错位 / 建议管理层……”等说法；热度缺口只按方向中性描述（如“分析师关注度高于管理层主动提及”）。
- 第三方文字稿为三级来源，引语标“非官方逐字稿，待录音复核”；券商观点标“二手”。
- 涉及未公布业绩的讨论只能在私有化工作区进行。
