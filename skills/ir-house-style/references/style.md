# IR 写作与证据规范（详细版）

## 1. 结构
- 标题：一句话结论，写事实与数字，不评价任何公司的管理层或其表述。例：“Meta 上调 2026 年资本开支指引下限，分析师追问集中在 2027 年投入节奏”。
- 第一段：三条要点，每条一句，带数字。
- 正文：每段只讲一件事；表格优先于长段落。
- 结尾：同业做法观察（标〔推断〕，只写同业做了什么、分析师如何反应，不构成口径建议）与腾讯可能被追问的问题（只列问题，不附建议答法）。

## 2. 数字格式
| 情形 | 写法 |
|---|---|
| 人民币金额 | 中文材料用“亿元”，保留到小数点后一位（如 2,048.4 亿元）；引用英文原文时保留原单位（RMB204.8 billion） |
| 港元 | “亿港元” |
| 美元 | “亿美元”，并注明汇率假设与日期 |
| 同比 | “同比 +11%”；百分点变化写“+3 个百分点” |
| 推算值 | 数字后加“（推算）”并在注释写明算法 |
| 日期 | 2026-10-26；季度写 2026Q2 |

## 3. 来源层级
| 层级 | 例子 | 用法 |
|---|---|---|
| 一级 | 公司公告、港交所披露、SEC 文件 | 可直接引用 |
| 二级 | 官方网络直播、官方新闻稿 | 可直接引用 |
| 三级 | 第三方业绩会文字稿 | 标“非官方逐字稿”，对外引用前用官方录音复核 |
| 四级 | 媒体报道、券商观点转述 | 标“媒体转述/二手”，不作为事实依据 |

## 4. 证据标签
- 〔公开披露〕：原文可查。
- 〔结构化数据〕：来自交易所或数据接口的表格数据（如港股通持股）。
- 〔计算〕：由上述数据计算得出，算法可复现。
- 〔推断〕：作者判断，包括所有因果解释。

## 5. 已公开表述索引的格式
| 字段 | 内容 |
|---|---|
| 原话 | 逐字摘录，≤40 个汉字或 25 个英文单词 |
| 出处 | 文件名 / 网址、日期、来源层级 |
| 核查状态 | 已逐字核对 / 待录音复核 / 仅媒体转述 |

## 6. 水印文本
内部准备材料，不构成公司口径。

## 7. 禁用词
颠覆、革命性、首创、全面领先、赋能、取代 IR。
