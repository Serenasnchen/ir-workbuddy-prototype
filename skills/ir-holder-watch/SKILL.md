# 股东、资金与回购监测（ir-holder-watch）

先加载 `ir-house-style`。

## 输入
- 股票代码（如 00700）、监测起止日期。
- 下一次审议业绩的董事会会议日期（来自港交所董事会会议通知）。
- 阈值配置 `references/alerts.md`（可按部门要求修改）。

## 步骤（在工作空间根目录运行）
1. **港股通（南向）持股（脚本）**：`python scripts/southbound.py 700 --from 2026-10-01 --to 2026-10-23`，从港交所披露易逐日抓取持股股数与占比（本地缓存，重跑不再联网），并计算日变化。如需估算净买卖额，用“股数变化 × 收盘价”，结果标〔计算〕并注明价格来源。
2. **回购（脚本）**：先从港交所披露易“标题搜寻”下载本年度全部“翌日披露报表”PDF 到 `nddr/`，再运行 `python scripts/buybacks.py nddr --year 2026`，得到逐日股数、金额、高低价、均价与合计，并自动检查每日均价是否落在所报高低价之间（不自洽的原件只标出、不推断原因）。
3. **回购禁止期（脚本）**：`python scripts/blackout.py --board 2026-11-18 --last-buyback 2026-10-15`，按上市规则第 10.06(2)(e) 条推算禁止窗口（标〔计算〕），与“观察到的最后一笔回购日”（标〔公开披露〕）分开展示，不推断原因。
4. **主要股东与权益披露**：汇总定期报告披露的主要股东持股与权益披露申报的变动；不展示董事个人交易。
5. **提醒**：对照 `references/alerts.md` 的阈值生成提醒（如南向单日净卖出超过阈值、主要股东权益跨越整数百分比、回购恢复或暂停），每条附数据与来源。
6. **出简报**：一页晨报（结论先行 + 图表 + 提醒），可配置为定时任务推送到企业微信。

## 输出
- `holders.json`（时间序列、对账结果、窗口日历、提醒）。
- `holder_brief.md`（一页晨报）。

## 红线
- 只读公开数据；不提供交易、回购节奏或择时建议。
- 资金流与股价之间的任何因果解释标〔推断〕。
- 投资者个人资料不进入本技能。
