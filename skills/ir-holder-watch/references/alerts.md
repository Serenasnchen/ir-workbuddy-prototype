# 提醒阈值（示例，可由部门调整）

| 规则 | 默认阈值 | 数据来源 | 说明 |
|---|---|---|---|
| 南向单日净卖出（估算） | 超过 10 亿港元 | 港交所港股通持股 × 收盘价 | 估算值，标〔计算〕 |
| 南向持股占比变化 | 5 个交易日累计变动超过 0.2 个百分点 | 港交所港股通持股 | |
| 托管商持股异动 | 单一参与者单日变动超过已发行股本 0.1% | 港交所 CCASS 持股 | 托管商层级，非最终受益人 |
| 主要股东权益变动 | 跨越整数百分比 | 港交所权益披露 | 申报有 3 个营业日时滞 |
| 回购状态变化 | 连续 5 个交易日无回购，或暂停后恢复 | 翌日披露报表 | 只报事实，不推断原因 |
| 窗口期提醒 | 回购禁止期开始前 3 个交易日 | 上市规则第 10.06(2)(e) 条 | 日历以合规部门为准 |
