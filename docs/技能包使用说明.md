# IR 技能包使用说明

本技能包含 5 个按 SKILL.md 标准编写的 WorkBuddy 技能，只处理公开资料。每个技能是一个 zip，解压后为一个文件夹：`SKILL.md`（用途、步骤与红线）、`manifest.yaml`、`references/`（模板与规范）和 `scripts/`（Python 脚本）。

| 技能 | 用途 | 主要脚本 |
|---|---|---|
| ir-house-style | 写作与证据规范，其余技能都会先加载它 | — |
| ir-number-gatekeeper | 中英文业绩材料数字勾稽；检查草稿里的数字是否与已披露一致 | gatekeeper.py |
| ir-peer-flash | 同业发布业绩后，按 8 个固定议题出一页速评，并逐字核对引语 | extract_numbers.py、check_quotes.py |
| ir-qa-radar | 从历次业绩会文字稿统计管理层与分析师的话题分布，整理预测议题与已公开表述 | parse_transcripts.py、heat.py、prereg.py |
| ir-holder-watch | 港股通持股、回购与回购禁止期的只读监测 | southbound.py、buybacks.py、blackout.py |

## 在 WorkBuddy 中安装
1. 左侧边栏进入“专家 · 技能 · 连接器”，选“技能”页签。
2. 点“添加技能 → 上传技能”，先上传 `ir-house-style.zip`，再上传其余 4 个。
3. 在“已安装”中确认 5 个技能均已启用。
4. 使用时在对话里写明技能名，例如：“使用 ir-number-gatekeeper 技能，核对 inputs 文件夹里中英文新闻稿的数字。”

## 不经 WorkBuddy 直接运行脚本
需要 Python 3.9 及以上；处理 PDF 时另需 `pymupdf`（纯文本输入不需要）。以下命令在技能文件夹内运行，路径按实际位置替换。

```
# 数字守门员：两份新闻稿勾稽，再检查一段草稿
python scripts/gatekeeper.py tieout --doc release_en=2Q26_release_en.txt --doc release_zh=2Q26_release_zh.txt --out out
python scripts/gatekeeper.py check --draft draft.txt --doc release_en=2Q26_release_en.txt --doc release_zh=2Q26_release_zh.txt --out out

# 同业速评：抽取新闻稿数字；核对速评中的引语
python scripts/extract_numbers.py meta_release.pdf --out numbers.json
python scripts/check_quotes.py flash.md meta_transcript.txt

# 问题雷达：解析文字稿，计算话题热度，封存预测议题
python scripts/parse_transcripts.py transcripts parsed
python scripts/heat.py parsed --units question_units.json --out heat.json
python scripts/prereg.py seal top10_prereg.json

# 股东监测：回购禁止期推算
python scripts/blackout.py --board 2026-11-18 --last-buyback 2026-10-15
```

各脚本的完整参数见对应 SKILL.md。

## 使用边界
- 只用于对内准备与核查；不对外发送任何内容，不代拟公司口径。
- 未公布的业绩、讲稿与回购计划只应在私有化部署的工作区中处理。
- 第三方文字稿不是官方逐字稿，引用前须以官方录音复核。
